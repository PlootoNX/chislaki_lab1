# AGENTS.md

## Обзор проекта

Учебная лабораторная работа №1 по курсу численных методов («Число обусловленности
и чувствительность на дискретной модели»). Постановка задачи — в файле `lab1.pdf`
(на русском языке).

Задача: подсчитать число решений сравнения `a^y ≡ c (mod b)` для `y ∈ [0, b−1]`
и сравнить три реализации подсчёта:

- `count_naive` — наивная: `a^y` вычисляется заново умножением в цикле для каждого `y`;
- `count_fastpow` — через быстрое возведение в степень (`binpow`, бинарное возведение);
- `count_iter` — итеративная: степень накапливается одним умножением на `a` за итерацию.

Во всех трёх реализациях промежуточные результаты сокращаются по модулю `b`
после каждого умножения (`binpow` принимает `mod` третьим аргументом), поэтому
огромные числа не возникают и функции сравнивают уже остатки: `a^y mod b == c mod b`.

По условию лабораторной нужно понять, какая из реализаций применима, и почему для
дискретных (недифференцируемых) моделей число обусловленности определяется
перебором возмущений, а не через производную.

## Текущее состояние

1. **Тесты проходят.** Все три реализации (`count_naive`, `count_fastpow`,
   `count_iter`) считают решения для `y ∈ [0, b−1]` одинаково и согласованы
   с эталонами `ans` в `tests.py`; `main.py` печатает `3\n3\n3` для `(3, 11, 1)`.
   Исправленные ошибки (история): `count_iter` раньше умножал на `a` до проверки
   и пропускал `y = 0`; два эталона в `ans` были неверны
   (для `(3,11,1)` верно 3, для `(0,7,0)` верно 6).
2. **Проверочная таблица в разделе 6.1 `lab1.pdf` содержит ошибки.** Значения
   `N(3;11;1)=1` и `N(0;7;0)=1` противоречат определению из раздела 3 того же PDF
   (`y ∈ {0,...,b−1}`, `0^0 = 1`): верно `N(3;11;1)=3` (y = 0, 5, 10) и
   `N(0;7;0)=6` (y = 1..6). Эталоны в `tests.py` намеренно взяты по определению
   из раздела 3, а не из таблицы — не «исправлять» их обратно на значения из PDF.
3. `.mypy_cache` содержит кэш под Python 3.14, но mypy в окружении не установлен;
   типизация в коде отсутствует.
